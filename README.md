# Joblo Web

Website and lead dashboard for Joblo Web, built with [Zite](https://zite.com).

- React + Vite + Tailwind front end (`src/`)
- Backend endpoints in `src/api/` (quote form, lead dashboard)

Note: this code uses Zite's `zitejs/*` modules (database, auth, API callers) and shared UI components from `@project/components` (shadcn/ui). To run it outside Zite, replace those with your own equivalents.
