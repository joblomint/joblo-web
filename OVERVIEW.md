# Joblo Web

Public website for Joblo Web, an independent web design studio in Kenya. It shows services with starting prices (from KSh 10,000), past work, the process, an About section and an FAQ. It collects quote requests through a form and WhatsApp.

Quote requests are saved to the database, and the owner manages them in a private lead dashboard at /dashboard. Access is limited to the emails in the Admins table. The quote endpoint works as a public API, so other sites or tools can send leads too.

Intended custom domain: jkate.co.uk.
